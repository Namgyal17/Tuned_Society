# Garage Logos

Store garage logo images in this directory.

## Naming Convention
Name the image files using the garage's **slug** (URL-friendly name).
The application will automatically try to load `[slug].png` for each garage.

**Format:** PNG (Preferred)
**Dimensions:** Square (e.g., 200x200px) recommended.

### Examples:
- **Garage Name:** Wheelerz Hub -> **Slug:** `wheelerz-hub` -> **File:** `wheelerz-hub.png`
- **Garage Name:** Auto Meister -> **Slug:** `auto-meister` -> **File:** `auto-meister.png`

## Cover Photo Guidelines (Homepage Banners & Cards with "Book Now")

For the homepage garage banner cards displaying the **Book Now** button:

- **Aspect Ratio:** **`16:9`** (Landscape Widescreen / `1.78:1`)
- **Card Render Container:** `330px` width x `185px` height
- **Recommended Resolutions:**
  - **Standard HD (16:9):** `1280 x 720 px` or `1920 x 1080 px` (High Quality)
  - **Retina 2x:** `660 x 370 px`
  - **Retina 3x:** `990 x 555 px`
- **Format:** JPG or PNG (Landscape photo showing workshop / garage bay)
